# 테스트로 발견해 수정한 오류

이번 E2E 확장 및 수정 작업 전체를 대상으로 정리했다. 아래 행은 관련 증상을
묶은 결함군이며, 테스트 시나리오 수나 최초 실패 횟수를 오류 개수로 계산하지 않았다.
최종 전체 검증은 **4,351개 통과**: 단위 3,491개, E2E 860개.
타입 검사 오류·경고 0개. [전체 결과](E2E-FULL-RESULTS.md)와
[사례별 통과 목록](E2E-FULL-PASSES.tsv)에 실행 근거를 보관했다.

## 제품 오류와 구분한 테스트 자체의 오류

- 팝업 내부 선택자를 중첩하거나, 선택된 색상 버튼의 이름을 잘못 가정한 경우.
- 문제 개수가 붙는 Validate 메뉴를 정확히 `Validate`로만 찾은 경우.
- macOS의 Control+클릭을 일반 다중 선택 클릭으로 가정한 경우.
- 로컬 공유 사본을 읽기 전용으로 가정하거나 1.1배 확대 5회를 150%로 계산한 경우.
- CSS 행렬 반올림, 초기 정규화 저장, 자동 저장 완료 전에 비교한 경우.
- 폐기된 MCP 키의 403 응답을 401로 기대한 경우.
- Docker 호스트 임의 포트와 컨테이너 내부 PORT를 혼용하거나 재시작 후 주소 변경을 고려하지 않은 경우.

이 항목들은 테스트 입력·기대값·동기화를 수정했다. 제품 오류 건수에 포함하지 않았다.
최종 전체 실행에서는 추가 수정 없이 모든 테스트가 통과했다.
