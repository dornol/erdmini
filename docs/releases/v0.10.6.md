## Highlights

This patch improves data preservation, permissions, collaboration and import/export
correctness, with comprehensive end-to-end coverage.

### Fixes

- Preserve the latest edits during autosave, project/language changes and project
  deletion. Keep schema-save warnings visible when only viewport saving succeeds.
- Apply permission changes to open editors, pending confirmations and connected
  collaboration sessions; prevent writes after downgrade or revocation.
- Keep concurrent table, column, constraint, domain and memo operations consistent
  across clients, persistence and undo/redo.
- Preserve quoted identifiers, ENUM values, precision and native type semantics
  across SQL dialect imports/exports. Reject invalid domain dimensions.
- Move attached memos during layout, exclude locked tables from alignment, and
  make a memo resize a single undoable gesture.
- Reveal hidden schemas when navigating search results and retain legacy projects
  when initializing the first administrator.
- Harden OIDC/LDAP validation, provider error recovery, MCP input validation and
  database restore/rollback behavior.

### Interface and maintenance

- Improve responsive canvas layout, empty states and menu pointer interactions.
- Add coverage for local/server editing, authentication, collaboration, all 89 MCP
  tools, historical database restoration, startup and Docker/Compose deployment.
- Run type checking and unit tests in automatic CI. Long E2E suites run locally or
  through the separate **Manual E2E** GitHub Actions workflow.

### Validation

- **3,491 unit tests passed** across 112 files.
- **860 E2E tests passed**: 374 local, 477 server, 5 startup and 4 Docker/Compose.
- Type checking: **0 errors, 0 warnings**.
- Complete suite passed without failures, skips or retries before the release
  version bump and CI-only changes.
